# Hi, I'm Ettore 👋

Experimental physicist finishing a **PhD in Applied Physics** at [LIPhy](https://liphy.univ-grenoble-alpes.fr/fr), Université Grenoble Alpes (defence: December 2027).

I build and automate optical benches in Python, and I want to put optics, materials and data to work for the **energy transition**.

### What I work on
- **Wavefront shaping & digital holography** – off-axis holography with a DMD, transmission matrices, focusing light inside scattering media
- **Femtosecond laser processing of glass** – MSc thesis in industrial R&D at [FEMTOprint](https://www.femtoprint.ch/) (Switzerland)
- **Data analysis & machine learning** – MSc in Business Analytics (Quantic): gradient boosting, cross-validation, cost–benefit analysis

### Featured project
**[Glazing Retrofit Prioritization Tool](https://github.com/EttoreBertolini/meridian_capstone_Bertolini)** – ranks window retrofits across a building portfolio by energy saved and payback, using a gradient boosting model trained on NREL/DOE ComStock building simulations.

### Tools
Python for instrument control (DMD, scientific cameras, piezo stages) and data analysis
